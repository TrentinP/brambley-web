Brambley Notes content lives in this directory as Markdown or MDX files.

This migration intentionally does not reconstruct missing Squarespace post text from memory.

Expected frontmatter:

---
title: "Post title"
date: 2026-09-03
subtitle: "Optional subtitle"
excerpt: "Optional index excerpt"
draft: false
---

The filename becomes the public slug. For example:

finding-brambley.md -> /blog/finding-brambley/

Once the Squarespace blog export is available, preserve the existing titles, dates,
slugs, text, links, and images as closely as the source permits. Visual redesign
should be handled separately from content migration.
